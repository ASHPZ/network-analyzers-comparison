# Network Protocol Analyzers: Wireshark vs. tcpdump

## 📌 Project Overview
This project is part of the **Google Cybersecurity Professional Certificate** on Coursera. The objective is to investigate and visually document the differences and similarities between two industry-standard network protocol analyzers: **Wireshark** and **tcpdump**.

## 🎯 Objectives
- Analyze the core functionalities of GUI-based and CLI-based packet sniffers.
- Identify the appropriate use cases for both tools in cybersecurity operations (e.g., incident investigation, attack detection).
- Present findings in a structured comparative diagram (Venn diagram approach).

## 📊 Comparative Analysis Summary

### Wireshark (GUI)
- Employs a **Graphical User Interface (GUI)** for deep packet inspection.
- Offers advanced features like colorizing and complex dissection.
- **Resource-heavy**: Consumes more system resources and may have hardware limitations during massive captures.

### tcpdump (CLI)
- Employs a **Command-Line Interface (CLI)**, making it ideal for remote server management.
- **Lightweight**: Consumes minimal system resources.
- Native to Unix-family operating systems.

### Similarities
- Both are **open-source** and freely available.
- Both serve as fundamental **network protocol analyzers**.
- Both allow for powerful, protocol-specific traffic filtering.
